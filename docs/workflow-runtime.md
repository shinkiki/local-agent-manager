# 워크플로 공통 실행설정

워크플로 관리에서 `start_chat` 단계가 있는 계약을 선택하면 공통 실행설정이 표시된다.
공급자별로 입력하지 않고 이 워크플로가 시작하는 일반 채팅 전체에 적용한다.

- **무인 개발 설정**: 전체권한(`fullAccess`), 실행 승인 생략(`never`), 추천안 자동 선택(`recommended`).
- **기존 단계 설정 사용**: 공통 덮어쓰기를 제거하고 각 `start_chat` 단계의 원래 설정을 사용한다.
- 모델·계정·작업 경로·추론 수준·페이싱 상한은 바꾸지 않는다. 전역 및 다른 채팅 설정도 바꾸지 않는다.

계약의 선택 필드 `chatRuntime`은 `mode`, `approvalMode`, `decisionPolicy`만 받는다.
각 필드를 생략하면 해당 단계의 값이 유지된다. 템플릿을 해석한 뒤 실행과 감사 기록 전에 적용한다.
기존 계약에서 이 필드가 없으면 기존 계약 지문과 동작을 유지한다.

`recommended`는 허용 범위의 선택을 에이전트가 수행하도록 하는 지침이며 권한 부여나 목표 달성을 보장하지 않는다.
전체권한은 작업 경로 밖의 파일·명령 접근도 허용할 수 있다. Antigravity의 권한 승인 동작은
권한 범위(`mode`)에 따른다. AIA 채팅은 이 덮어쓰기 대상이 아니며 시스템 에이전트 설정을 따른다.

저장은 계약 제안 검증 → 영향 요약 확인 → 새 버전 등록 순서다. 기존 페이싱 회차의 승인 버전을
몰래 바꾸지 않는다. 계약을 수정한 경우 회차 편집기에서 새 버전을 승인·저장해야 하며,
그 뒤 동일 승인 버전의 예약 회차마다 다시 확인하지 않는다. 실행 중인 채팅은 바꾸지 않는다.
동시에 다른 편집이 저장되면 버전 충돌로 거절한다. 되돌릴 때도 이전 값으로 새 버전을 저장한다.
